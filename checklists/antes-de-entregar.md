# Checklist antes de entregar

Usar antes de que el usuario entregue una propuesta, capítulo o paper — idealmente en conjunto con `modules/revisor-2.md` para la parte de contenido.

- [ ] La pregunta de investigación, los objetivos y la conclusión son coherentes entre sí (no se pregunta una cosa y se concluye otra).
- [ ] Todas las citas fueron verificadas — ninguna fue completada de memoria por si "sonaba plausible".
- [ ] El formato de citas y referencias es consistente en todo el documento (un solo estilo, no mezclado).
- [ ] El vacío de investigación que justifica la tesis está explícito, no implícito.
- [ ] Las limitaciones del propio estudio están declaradas, no solo las de los estudios ajenos citados.
- [ ] Ninguna conclusión generaliza más allá de lo que el diseño metodológico permite (p. ej., causal a partir de datos correlacionales).
- [ ] El documento cumple la extensión, formato e idioma exigidos por la institución, si se conocen.

Si el usuario no ha mencionado los requisitos exactos de formato de su institución, preguntar antes de asumir uno por defecto.

---

**Formato de entrega:** usar el componente de checklist con barra de progreso (ver `assets/guia-html-interactivo.md`).
