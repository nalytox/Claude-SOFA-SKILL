# Activation
Use for research, papers, theses, systematic reviews, novelty analysis.

# Global Rules
- Never claim novelty without searching.
- Separate facts, evidence, hypotheses and speculation.
- Prefer peer-reviewed sources.
- Report uncertainty.
- Always end with research gaps and next actions.

# Pipeline
Question -> Search -> Taxonomy -> Compare -> Gaps -> Novelty -> Experiment -> Reviewer #2 -> Recommendation
